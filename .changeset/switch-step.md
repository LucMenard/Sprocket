A new kind of step, **Switch**, takes one of several branches by a value, for example the kind of work an agent found: bug, feature, review. Each case is a branch named after the value it takes, compared without case. A default branch takes any other value; without one, a value with no case fails the step. Add it from the editor's palette, and name, add or remove its cases in the inspector.
